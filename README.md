# Money Bag

Interfaz de una app personal de inversiones (web app instalable en el celular).

Este repositorio **solo contiene la pantalla**: HTML, CSS y JavaScript. No contiene datos de
ninguna cuenta. Los datos viven en una base de datos aparte y solo se muestran después de
iniciar sesión con el correo autorizado.

- Precios en vivo cada vez que se abre la app.
- Niveles técnicos, fundamentales y datos de cuenta calculados una vez al día.
